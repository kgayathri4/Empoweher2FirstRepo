Enhanced Todo List:

A simple and clean Todo List application built with HTML, CSS, and JavaScript.
You can add tasks, delete them, mark them as completed, and search through your tasks.
All tasks are saved in your browser using LocalStorage.

Features:
  Add new tasks
  Delete existing tasks
  Mark tasks as completed
  Search tasks instantly
  Saves tasks automatically (LocalStorage)

How to Use:
  Open index.html in your browser.
  Type a task and click Add Task.
  Click a task to mark it complete.  
  Use the search box to filter tasks.
  Click Delete to remove a task.
